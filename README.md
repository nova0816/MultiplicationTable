# 🌟 九九乘法大冒險 (9x9 Multiplication Adventure)

專為 **7 歲小朋友** 設計的九九乘法趣味互動闖關遊戲集！
主要支援 **iPad（平板 Safari）**，次要支援 **Android 手機（Chrome）**。

## ⚡ 測試方式（最簡單，雙擊即玩！）
本專案已全面整合為 **零依賴、純前端自包含架構 (Self-Contained HTML5)**：
1. **本機電腦雙擊測試**：直接在檔案總管中雙擊 `index.html`，即開即玩，不需要開任何伺服器或安裝任何軟體！
2. **iPad / Android 手機測試**：
   - 方式 A：透過 AirDrop、LINE、雲端硬碟或郵件將 `index.html` 傳至手機/平板點開。
   - 方式 B：電腦開本機伺服器 `python -m http.server 8000`，手機平板輸入 `http://電腦區網IP:8000`。
   - 方式 C：推到 GitHub 開啟 GitHub Pages（見下方教學）。

## 🎯 乘法表自選系統 (2, 3, ... 9 自由勾選)
- 主選單提供 **2、3、4、5、6、7、8、9** 的大型按鈕，支援各自分別勾選與取消。
- 提供【全部 (2~9)】、【基礎 (2, 3, 5)】、【進階 (6, 7, 8, 9)】快捷預設鈕。
- 頂部導航即時顯示目前練習段落（例如「目前練習：2, 3, 5 的乘法表」）。
- 所有 6 款遊戲完全動態套用所選數字出題！

## 🎮 六大核心遊戲說明

1. **👾 貪吃怪獸餵食秀（拖曳配對型）**：
   - 怪獸頭頂顯示乘法算式，上方飄下美味食物（甜甜圈、漢堡、披薩）。
   - 手指拖曳正確答案食物進入怪獸嘴中（亦支援直接點擊飛入）。
   - 答對開心打飽嗝噴愛心；答錯如果凍般彈回原位，怪獸露出困惑表情不扣分。
2. **🐸 叢林跳跳蛙（路徑闖關型）**：
   - 青蛙舉著算式牌子過河，點擊正確荷葉跳躍前進。
   - 點錯荷葉沉下濺起逗趣水花，游回上一葉重試。
   - 連續答對 3 題觸發「🌈 彩虹加速」，一次跳過兩格直奔國王寶箱！
3. **🧪 魔法藥水調配師（逆向拆解型）**：
   - 精靈與動物客人指定能量值（例如 24）。
   - 桌面擺放 1 至 9 材料瓶，小朋友挑選 2 個丟進大鍋爐。支援多種因數解法（如 $3 \times 8$ 或 $4 \times 6$）。
   - 答對冒七彩煙霧變出藥水；答錯冒小黑煙提示「目前能量是 18 喔，再試試！」。
4. **🚀 太空隕石防衛戰（快速點擊型）**：
   - 隕石緩緩飄落，下方設有 4 座能量砲台，點對發射雷射擊碎隕石，支援手機震動回饋！
   - 支援「悠閒練習模式」（慢速、護盾抵擋提示）與「小小英雄模式」（60 秒計時、連擊 Combo 加成）。通關 10 顆隕石即過關！
5. **🃏 親子翻翻樂對決（記憶對決型）**：
   - 支援 12 張（6 組）或 16 張（8 組）卡牌切換，一半算式一半答案。
   - 支援「單人自我挑戰」與「雙人親子對決（小勇士 vs 家長隊輪流翻牌）」。
   - 答案數值相同即可成功配對（支援同值多算式如 3×4=12 與 4×3=12）。
6. **🧩 乘法方塊大挪移（算式拼圖解謎型）**：
   - 呈現 `[ 方塊 A ] × [ 方塊 B ] = 目標值` 算式，初始方塊隨機打亂。
   - 支援觸控點選兩兩互換方塊，調至正確算式後點「確定檢查」。
   - 關卡進階制度：從 2 排（第 1~3 關）、3 排（第 4~6 關）、4 排（第 7~9 關），到 5 排（第 10~12 關）共 12 關大破關！

## 🚀 推送到 GitHub 與開啟 GitHub Pages

```bash
git init
git add .
git commit -m "feat: 九九乘法大冒險兒童遊戲集 (自包含HTML5，支援2~9自選與5大遊戲)"
git branch -M main
git remote add origin https://github.com/<你的使用者名稱>/<你的倉庫名稱>.git
git push -u origin main
```
推送後至 GitHub 倉庫的 **Settings $\to$ Pages** 選擇 `main` 分支 `/ (root)` 按下儲存，即可在 iPad 與手機上隨開隨玩！
